# Climb Now 🧗

**Less Planning. More Climbing.**

Climb Now is an availability-first climbing partner matching application designed to help indoor climbers find partners based on overlapping schedules and gym locations.

Unlike traditional social networking platforms, Climb Now focuses on scheduling compatibility rather than profile browsing or social discovery.

## How It Works

1. **Set Availability** — Choose your climbing gym, date, and available time.
2. **Automatic Matching** — The system identifies climbers with overlapping schedules.
3. **Confirm Session** — Accept a compatible match.
4. **Climb Together** — Meet at the gym and enjoy climbing.

## Project Goals

- Simplify climbing partner coordination.
- Reduce unnecessary scheduling conversations.
- Build an automated availability-based matching engine.
- Provide a lightweight, privacy-conscious experience.
